🛡 Sentinel — Token Risk Guard

A wallet-security agent that reads live on-chain state and exposes the owner powers hiding inside an EVM token contract — mint, pause, blacklist, fee control, upgradeability — as a transparent 0–100 risk score pinned to a block number, with the raw evidence attached.

Screening aid only — not financial advice. Every check is reproducible from the pinned block: re-run the same eth_call / eth_getCode / eth_getStorageAt calls at that block and you will get the same evidence. Selector presence is a bytecode heuristic, not a guarantee. Built for the Agent Games Wildcard track.
